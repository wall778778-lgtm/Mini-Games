About Mini Games

Mini Games is an independent collection of browser games for short play sessions. The library brings arcade challenges, logic puzzles, memory games, and quick reaction tests together in one place.

How the games work

Choose a title from the game library to open its own page. Each game explains its objective and controls; depending on the game, you can use a keyboard, mouse, touch screen, or on-screen buttons. Game play runs in your browser and does not require an account or app installation.

Keeping the collection useful

The game library is maintained as a small web project. We update pages as issues are reported. If a control does not work on your device or a link is broken, include the game name and page address when you contact us.

Questions or feedback

Use the Contact page to report a problem or send a suggestion.
